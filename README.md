那六年，我把班级多媒体折腾到蓝屏过很多次（再次忏悔 🙏），却也因此对计算机着了迷。
期间多次参加 **编程 / 计算机类比赛** 并拿到奖项，最终拿下了一级证书——那是我的第一张"官方认证"。

### 🔧 初中 · 班里的"技术担当"

兴趣不降反增。帮班级 **维修多媒体、重装系统**，在课堂上现场给老师解决技术问题。
**能帮助到老师，是我的荣幸。** 这三年结束时，我以 **优秀毕业生** 的身份毕了业。

</div>

### 🌈 高中 · 到目前为止最快乐的时光

大家对我都很好，这段日子我会一直记得。而现在，我正在用自己的努力，为将来的高考做准备。

</div>

接下来：一边备战高考，一边继续写代码。
